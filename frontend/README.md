# Sunflower Animation - Frontend (Phase 2 Workspace)

This directory is reserved for **Phase 2: Frontend & Canvas Animation**.

### Planned Stack & Features for Phase 2:
- **Interactive Sunflower Canvas**: Procedural math-driven botanical animation (Fibonacci phyllotaxis seed patterns, swaying stalk, dynamic unfurling petals).
- **Live Garden Dashboard**: Real-time stats display (Growth Stage, Hydration, Sunlight, Height, Flower state).
- **Interactive Nurture Controls**: One-click action buttons (Water 💧, Sunlight ☀️, Fertilize 🌿).
- **Multi-Sunflower Carousel/Grid**: Switch between different planted sunflowers.
- **REST API Client**: Integrated with the `/backend` endpoints.
